============================================================
1. PROJECT KA MAIN PURPOSE
============================================================

Sanjeevani Clinic ek healthcare web application hai jisme
patient ke liye screening, chatbot assistance, doctor
information, appointment booking, medical document handling
aur healthcare related assistance provide ki ja sakti hai.

Project mein do major development parts add kiye gaye hain:

1. AI/Healthcare Chatbot Module
2. K-Means Based Analytics Module

Existing clinic website ke saath in dono modules ko integrate
kiya gaya hai.


============================================================

============================================================

Project mein mainly do types ke users hain:

A. Patient / Normal User
B. Admin / Super Admin
